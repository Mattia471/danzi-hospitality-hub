# Contribuire

Questo repository ospita un **progetto cliente**. Le modifiche vengono valutate dal manutentore e devono rispettare l'identità visiva D’Anzi e i diritti sugli asset.

## Flusso consigliato

1. Apri una issue per bug o richieste di modifica, evitando dati sensibili.
2. Crea un branch descrittivo (es. `fix/partner-map` o `feat/catalog-gallery`).
3. Mantieni le modifiche piccole e pertinenti; evita nuove dipendenze senza necessità.
4. Esegui `pnpm lint` e `pnpm build`.
5. Apri una pull request con riepilogo, schermate se cambia la UI e istruzioni per il test.
6. Verifica responsive, accessibilità di base, link interni ed eventuali documenti Drive.

## Convenzioni

- React + TypeScript; contenuti in italiano, proprietà dei dati in inglese.
- Componenti e classi Tailwind coerenti con il design esistente.
- Non aggiungere un backend o servizi esterni per semplici modifiche editoriali.
- Niente credenziali, PDF riservati o dati personali nel repository.
- Non inserire fotografie, marchi o cataloghi senza autorizzazione di pubblicazione.
- Non attribuire coordinate, sedi, architetti o crediti senza verifica.

Per nuovi partner, realizzazioni e cataloghi segui [docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md).
